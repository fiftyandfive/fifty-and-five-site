## Generation settings (apply to every prompt)
- **Aspect ratio:** 16:9
- **Resolution:** 1920×1080 minimum, 2400×1350 preferred
- **Style anchor:** "editorial photography, Apple product hero aesthetic, soft prismatic
  bloom, frosted glass undertones, gentle natural light, clean composition, premium feel,
  shallow depth of field, cinematic, no text, no logos, no signage"
- **Negative prompt:** `text, logo, watermark, signage, branding, label, words, letters,
  numbers, low quality, oversaturated, cartoon, illustration`
- **Format on save:** JPG, sRGB, 80–85 quality (target ≤ 280KB)
- **Filename:** match the existing path exactly (see header above each prompt)

## Workflow

1. Open Google AI Studio → Image generation → select **Imagen** or **Gemini 2.5 Flash
   Image (Nano Banana)**.
2. Set aspect ratio to 16:9.
3. Paste the **Style anchor + per-image prompt + Negative prompt** as one block.
4. Generate 3–4 variants per slot. Pick the one with the cleanest Liquid Glass
   feel — soft refractive bloom, no accidental text, premium negative space.
5. Save as JPG with the exact filename listed above into
   `/public/images/case-studies/`.
6. Commit + push to main. Vercel auto-deploys.

Total: 12 images. Budget ~30 minutes of generation + curation if you go fast.
